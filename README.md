# 🎓 Student Skill Gap Analyzer

A Python and SQL based application that analyzes a student's technical skills and compares them with the skills required for different job roles.

The system identifies the student's skill gaps, calculates a skill-match percentage, and recommends the skills they should learn to become more job-ready.

## 🚀 Features

- 🎯 Select a target job role
- 💻 Select existing technical skills
- 📊 Calculate skill-match percentage
- ✅ Display matched skills
- ❌ Identify missing skills
- 💡 Provide learning recommendations
- 🗄️ Store job roles and skills using SQL
- 🖥️ Simple graphical user interface using Tkinter

## 🛠️ Technologies Used

- **SQL**
